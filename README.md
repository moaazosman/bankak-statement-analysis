# 📊 محلل كشف حساب بنكك

تطبيق Streamlit يقرأ كشف حساب بنك الخرطوم (بنكك) بصيغة PDF ويحلله بالجنيه السوداني:
المستلم والمرسل، الرسوم والدمغة، أكثر الأيام نشاطاً، التصنيفات، ورسوم تفاعلية.

## التشغيل محلياً
```bash
pip install -r requirements.txt
streamlit run app.py
```

## النشر على GitHub + Streamlit Cloud
1. أنشئ مستودعاً جديداً على GitHub وارفع هذه الملفات (لا ترفع كشوفك الشخصية؛ `.gitignore` يمنع ملفات PDF).
2. افتح https://share.streamlit.io وسجّل الدخول بحساب GitHub.
3. اختر **New app** ← المستودع ← الفرع `main` ← الملف `app.py` ← **Deploy**.
4. ستحصل على رابط عام، ضعه هنا في README.

## الاختبارات
```bash
pip install -r requirements-dev.txt
pytest
```
الاختبارات تستخدم بيانات اصطناعية فقط. اختبارات الرسوم تُتخطّى تلقائياً إن لم تكن plotly مثبتة.

## التدقيق داخل التطبيق
يعرض التطبيق قسم «تدقيق البيانات»: الأسطر المكررة، التواريخ غير الصالحة، العمليات غير المصنفة،
الرسوم غير المرتبطة، ومطابقة الرصيد (الافتتاحي ← الختامي) كدليل على صحة القراءة.

## الخصوصية
الكود لا يكتب ملفات مؤقتة ولا سجلات ولا يستخدم cache مشتركاً؛ نتيجة القراءة تُحفظ في ذاكرة جلسة المستخدم فقط وتزول بانتهائها.
ملاحظة: Streamlit نفسه يُبقي الملف المرفوع في ذاكرة الخادم طوال الجلسة، وهذا خارج تحكم الكود.
عند النشر العام يستطيع أي شخص فتح الرابط، لذلك لا تضع كشفك الحقيقي داخل المستودع.

## الملفات
- `app.py` الواجهة
- `core.py` قراءة الـPDF والتصنيف والتحليل
- `charts.py` الرسوم
